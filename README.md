# Healthcare Centre Network Infrastructure

## Project Overview
A healthcare centre network designed and simulated using Cisco Packet Tracer.

## Objectives
- Configure department-wise VLANs.
- Enable inter-VLAN routing.
- Demonstrate network redundancy using HSRP and EtherChannel.
- Test connectivity between PCs and servers.

## Technologies
- Cisco Packet Tracer
- VLAN
- Inter-VLAN Routing
- HSRP
- EtherChannel
- DHCP and DNS

## Project Files
- `Healthcare_Centre_Network.pkt.pkt` - Packet Tracer project
- `documentation/` - Project documentation

## Testing
Connectivity is tested using ping commands and Cisco switch verification commands. Actual results will be documented after testing.

## Disclaimer
This is an academic network simulation project.
